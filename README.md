# Ishvari Swapnil Borsutkar — Professional Portfolio

Responsive React + Vite portfolio prepared from Ishvari's supplied academic, project, credential and profile details.

## Run
1. Extract the ZIP.
2. Open the `ishvari-professional-portfolio` folder in VS Code.
3. Open Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the Local URL shown by Vite.

## Verify before submission
Run `npm run build`. A successful build creates `dist`.

No backend/database is required. The contact form is frontend-only.
